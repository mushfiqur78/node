┌──────────────────────────────────────────────────────────────┐
│  Environment Variables Add করতে হবে?                        │
└──────────────────────────────────────────────────────────────┘

যদি /test endpoint এ "NOT SET" দেখায়:

1. Go to: https://vercel.com/dashboard
2. Your Project → Settings → Environment Variables
3. Add these:

   Name: MONGO_URI
   Value: mongodb+srv://user:pass@cluster.mongodb.net/real-estate?retryWrites=true&w=majority
   ✓ Production ✓ Preview ✓ Development

   Name: JWT_SECRET
   Value: your_secret_key_at_least_32_characters_long
   ✓ Production ✓ Preview ✓ Development

   Name: NODE_ENV
   Value: production
   ✓ Production ✓ Preview ✓ Development

4. Redeploy: Deployments → Latest → Redeploy (Cache OFF)
